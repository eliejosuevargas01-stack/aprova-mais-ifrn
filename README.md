# Aprova Mais IFRN

Landing page de vendas mobile-first para o material preparatório do Exame de Seleção do IFRN.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: identidade visual responsiva e microanimações.
- `script.js`: entrada dos elementos ao rolar e navegação suave.
- `assets/`: vídeos e artes de aprovação usados como prova social.

## Conteúdos para substituir

O player inicial usa diretamente o vídeo local enviado no briefing.
